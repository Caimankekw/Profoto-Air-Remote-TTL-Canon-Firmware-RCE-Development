## 地址与证据

地址均为 **PIC18 字节地址**，不是文件偏移；恢复应用镜像基址为 `0x4000`，首两个明文字节仍未知。`.partial.bin` 是分析表示，不能直接当作刷写文件。原恢复镜像 SHA256 为 `7f2b7ef2625bacebafc526d0623ae91faa1f544e6062f2d4171635ed087f072a`，已知字节掩码 SHA256 为 `81fe4da4f8a15728c97bc6de35fae71572d44f39a927dce22a9ca300b5d2558b`。

下述结论来自恢复的指令字节与有界离线回放。外设名称描述可见寄存器接口，不等于已证实全部 PCB 接线、bootloader 行为或物理时间。线性 PIC18 解码也可能把数据解释成指令，因此生成的列表仍是候选反汇编。

需要完整列表时，从项目根目录使用你持有的原厂 C11 Windows 更新程序生成：

```powershell
python tools/disassemble.py --original "C:\path\to\official_C11.exe" --out build/original_C11.listing.txt
```

默认地址范围为 `0x4002..0x9780`；可用 `--start`、`--end` 指定字节地址边界。工具仅离线运行，不访问设备，并核对支持的原厂输入。本目录不附整套汇编、个人设备读回或其他产品固件。

## 原厂 C11 与 AIR2-P8 的区别

| 范围 | 原 C11 已核实入口 | P8 改动或保留边界 |
|---|---|---|
| 按键 | `674A` 只返回一个按优先级选出的键码。加减为数字输入；A/B 共用 ADC field1；MODEL/HEAD 共用 field0；C 为独立数字输入。 | C+HEAD 分页；C+MODEL 切换记住的 MAN 子模式，仅这几个低频键等待组合。A/B/加减走直接单键路径。同一 ADC 不能提供 MODEL、HEAD 两个独立按下位。 |
| TTL / MAN | `60EA` 切 RAM `52`：非零为 TTL，零为 MAN。TTL 补偿使用 `3F..41` 与配置对象 `C+2..4`；`6212` 将反向模式布尔值写入 `C+5`；`9188/91A4` 处理相机侧布尔状态。 | 新增独立六组状态与最近 MAN 子模式。TTL ABC 补偿和手动目标分开；全局处于 TTL 时，DEF 仍是手动控制。 |
| 无线模块接口 | `783E/79D8` 发送 ASCII `RSGT1` 加 16 字节二进制体；`8930` 发送 ROM 字符串加 CR，可调用 `8656` 等四字节响应；`9636` 写 UART。 | 六组发送器经现有模块接口构造请求。UART 完成或本地响应不等于射频接收、灯端执行或相同 RF 时序。 |
| 相机 / HSS | `40A8` 分派相机命令，`421C` 处理 B4；`42DC/4308` 与 `43BC..4432` 是不同的预闪/主闪输出流程，主闪按原模式改变脉冲与 Q 输入的先后；`5F78` 处理能量计算与格式化。 | P8 保留本项目 HSS-P3 策略补丁及原无线后端。该补丁把能量准备移到 B4 主闪阶段；这不是未修改的 C11，也不是另一款引闪器 RF 后端的完整移植。 |
| 参数保存 | `54EE..550A` 把 FEC 同步到 `C+2..4`；原日志经软关机链 `8F38 -> 939E -> 662E` 提交，使用 `1F800` 区域。 | P8 另用运行时页 `F800..FFFF` 保存六组 A2 目标、Head/Model 意图、页面和模式记忆。A1 临时相对值不保存；原 FEC 保存时机仍独立。 |
| 频道 | `9474/75FC` 发送 `RSGER0\r` 读取；`64F8/8976` 应用并写频道，包括 `RSGEW00<channel>\r`。 | 这是无线模块参数通路，不应把原日志的 `C+6` 字段标成频道。 |

## 使用边界

- 原扫描和按键处理包含阻塞式去抖、长按、松键等待：`9226`、`8ACC`、`9086`。移除组合延时不代表任意速度连按都不丢键。
- 原软件 deadline 接口 `931C/7724`、时钟更新 `7F28` 的计数不能直接称作毫秒，需考虑硬件和采样条件。
- 原相机流程中的 S/Q 等待和输出脉冲，不足以证明模块内部状态机、RF-ready 回调或光学 HSS 均匀性。
- 参数保存、字节重建、更新程序复现分别证明各自检查结果，不能单独证明开机或硬件验收。请使用项目根目录的构建、验证与更新说明，不要编译本目录。
