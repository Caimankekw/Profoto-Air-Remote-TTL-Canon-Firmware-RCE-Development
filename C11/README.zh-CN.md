# 原 C11 逆向说明

[English](README.md) | 开发者：**Caimankekw**

这里精简说明**未修改的 Air Remote TTL-C C11** 中部分已确认行为。[recovered_logic.c](recovered_logic.c) 是人工编写的伪代码和地址索引，故意包含 `#error`；它不是厂商源码、完整反编译、安全可调用 API 或可编译固件。AIR2 修改实现位于独立的 [P8 分支](https://github.com/Caimankekw/Profoto-Air-Remote-TTL-Canon-Firmware-RCE-Development/tree/P8)。

全部地址均为 PIC18 **字节地址**，恢复应用的基址为 `0x4000`，首两个明文字节仍未知。原分析镜像 SHA-256 为 `7f2b7ef2625bacebafc526d0623ae91faa1f544e6062f2d4171635ed087f072a`，已知字节掩码 SHA-256 为 `81fe4da4f8a15728c97bc6de35fae71572d44f39a927dce22a9ca300b5d2558b`。这里不附带这些镜像；分析用 `.partial.bin` 也不是可直接刷写的文件。

| 范围 | 原程序字节地址证据与边界 |
|---|---|
| 按键 | `674A` 按优先级只返回一个键码。数字减/加键先于 MODE、另一数字键与 C；A/B 共用 ADC field 1，MODEL/HEAD 共用 field 0。ADC 三个闭区间为 `923..1023`、`412..612`、`60..260`（`6826/6844/684E/6858`）。这不能确定同一电阻梯形输入上多键同时按下的实际电压。 |
| TTL / MAN | `60EA` 切换 RAM `52`（非零 TTL，零 MAN）。活动 FEC 槽为 `3F..41`，对象 `C+2..4` 保存 TTL FEC；`6212` 将反向布尔值写入 `C+5`，相机路径 `9188/91A4` 再映射回来。对象指针在 RAM `42:43`，正常指向 `0088`。 |
| 显示 | `5DD4` 选择原模式/显示行为；`84C2`、`8414`、`83BC` 分别格式化三行。固定 LCD 标签不是任意字符显示区。 |
| 无线请求 | `783E/79D8` 发送 ASCII `RSGT1` 加 16 字节二进制体，无 CR。`8930` 发送 ROM 字符串加 CR，并可调用四字节接收例程 `8656`。`9636` 写 UART TXREG，返回不代表末位已发送、无线完成或灯具已应答。 |
| 相对功率 | `6B8E` 消费原相对调节队列，包括预查询、应答及超时/回退路径；它与相机能量命令路径分离。 |
| 相机 / HSS | `40A8` 分派相机命令；`421C` 的 B4 将 `19/23` 分为预闪路径，将 `25/2D/35/39/3D` 分为主闪路径。`42DC/4308` 与 `43BC..4432` 有不同输出序列及 S/Q 等待；`5F78` 按原模式/分类条件计算并格式化能量。这些边界不等于恢复无线模块完整状态机，也不证明光学 HSS 等价。 |
| 软件时基 | `931C` 建立 deadline，`7724` 检查，`7F28` 根据定时器观测推进软件时钟。原参数不能直接当作已校准毫秒。 |
| 原参数保存 | `54EE..550A` 将 FEC 镜像到 `C+2..4`。软关机链 `8F38 -> 939E -> 662E` 打包/比较位于 `1F800` 区域的原四字节 journal 记录，并非每次编辑自动写 Flash。 |
| 无线频道 | `9474/75FC` 请求 `RSGER0\r`；`64F8/8976` 应用/写入频道，包括 `RSGEW00<channel>\r`。不能将 journal 的 `C+6` 字段认作频道。 |

说明依据恢复字节与有界离线检查。寄存器别名不证明全部 PCB 连线、冷启动外设状态、具体 MCU 变体或 bootloader 行为；线性解码也可能把数据解释为指令。使用[根目录分析命令](../README.zh-CN.md#分析原-c11)，由自行提供且指纹匹配的原厂 EXE 生成候选列表；这里不附预生成固件或完整列表。
