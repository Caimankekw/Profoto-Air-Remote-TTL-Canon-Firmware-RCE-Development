# AIR2-P8 构建源码

这里是 Caimankekw 编写的 PIC18 补丁汇编器与链接器，采用 AGPL-3.0-only。
它们不是保富图原厂 C 源码，也没有替代完整原厂应用程序。构建命令见仓库根目录 README。

| 文件 | 职责 |
| --- | --- |
| `hss_patch.py` | 从源码及原 C11 算术代码构建现有 HSS 适配。 |
| `ui_patch.py` | 六组 UI、C+HEAD 翻页、C+MODEL 手动子模式及次要按键仲裁。 |
| `radio_patch.py` | 根据六组内部状态生成目标功率与开关指令。 |
| `persistence_patch.py` | V4 参数日志及旧格式迁移。 |
| `linker.py` | 两遍解析组件调用，保护 HSS、原生区域与保留参数页。 |
| `PROVENANCE.json` | 原创源码的原始散列及为独立构建所作的迁移说明。 |

`build.py` 只读取显式指定的原厂 C11 EXE 和本仓库文件。它通过 `reference/`
的参数解码受支持区域，从源码生成 HSS-P1 并修正头部校验，再链接 P8 组件。
不读取预构建 P1/P3 镜像、P3 更新器、设备备份、恢复采集记录或预计算的 P8 补丁配方。
封装配方在源码构建**之后**生成，再单独重放以校验封装。

冻结输出散列是发布检查条件。修改源码导致输出变化时会停止；发布新版本需重新验证
并更新预期散列。成功复现不等于已经验证真机、无线传输或物理时序。

partial BIN 的首字仍是未知占位，**不能作为直接刷写文件**。封装保留原始编码首字、
尾部、配置及内嵌固件资源之外的全部字节。C11 头部校验公式覆盖 `0x4002..0x4100`，
排除 `0x4050..0x4052`；这不代表已经恢复所有引导程序完整性检查机制。
